📖 Notudo Finance — SOP Runbook & Pipeline Docs
Step 1

🔐 Login Stockbit

File: pipeline/login.ipynb

Inisialisasi Edge WebDriver dengan profil khusus. Login Google secara manual lalu tekan tombol Q di keyboard untuk menyimpan sesi profil.

Step 2

📋 Scraping Daftar Emiten

File: pipeline/scrap-list-perusahaan.ipynb

Loop 10 sektor × sub-sektor di Stockbit menggunakan virtual scroll (scrollIntoView). Menghasilkan List-Perusahaan/Perusahaan.csv (~826 emiten).

Step 3

💹 Scraping Harga Saham

File: pipeline/scrap-all-harga.ipynb

Download data OHLCV historis per-emiten dari Perusahaan.csv dan simpan ke folder Dataset/[KODE].JK.csv (775 file CSV).

Step 4

📊 Scraping Broker Summary

File: pipeline/scrap-broker-summary.ipynb

Scraping aktivitas akumulasi/distribusi broker di Stockbit. Menggunakan auto-pause koneksi & proteksi skip ticker yang sudah lengkap (4-8 jam).

Step 5

🔄 Update Existing CSVs

File: pipeline/update_existing_csvs.py

Insersi kolom Sektor & Sub_Sektor dari Perusahaan.csv ke seluruh file CSV di folder Dataset/ setelah kolom Volume.

Step 6

🧪 Verifikasi Data

File: pipeline/test-read.ipynb

Verifikasi integritas dataset CSV, validasi kelengkapan kolom, dan pastikan tidak ada data korup sebelum di-publish.
