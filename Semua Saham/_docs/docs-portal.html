🗺️ Overview & Pipeline Flow

Gambaran besar project scraping data saham BEI. Pipeline ini mengumpulkan data harga historis + aktivitas broker dari 775+ emiten di Bursa Efek Indonesia.

Alur Pipeline Step-by-Step

1
🔐 Login Stockbit
login.ipynb
Inisialisasi Edge WebDriver dengan profil browser khusus Stockbit. Login manual satu kali — sesi tersimpan di profil, tidak perlu login ulang tiap run.
Setup
2
📋 Scraping Daftar Emiten
scrap-list-perusahaan.ipynb
Loop 10 sektor × sub-sektor di Stockbit. Virtual scroll trick via scrollIntoView. Output 826 emiten ke List-Perusahaan/Perusahaan.csv
~10 menit
3
💹 Scraping Harga Saham
scrap-all-harga.ipynb
Download data OHLCV historis tiap emiten. Simpan per-ticker ke Dataset/[KODE].JK.csv
~30–60 mnt
4
📊 Scraping Broker Summary
scrap-broker-summary.ipynb
Loop 775 ticker di Stockbit. Navigasi mundur per hari. Proteksi koneksi + validasi broker. Append kolom ke CSV yang sudah ada.
4–8 jam
5
🔄 Update & Migrasi CSV
update_existing_csvs.py
Tambah kolom Sektor & Sub_Sektor ke semua CSV dari mapping Perusahaan.csv. Sisipkan setelah kolom Volume. Skip file yang sudah punya kolom.
~1 menit
6
🧪 Verifikasi Data
test-read.ipynb
Baca & validasi hasil CSV. Cek kelengkapan kolom, struktur data, dan konsistensi output.
Manual

📖 Runbook / SOP

Standard Operating Procedure untuk menjalankan pipeline dari awal sampai selesai. Ikuti urutan ini setiap kali ingin scraping ulang atau update data.

⚠️ Prasyarat: Pastikan msedgedriver.exe di folder Driver/ versinya cocok dengan Microsoft Edge yang terinstall. Cek versi Edge di edge://settings/help
0
⚙️ Instalasi (Satu kali)
requirements.txt
  • Install Python dependencies yang dibutuhkan
  • Buat profil Edge khusus di path yang dikonfigurasi
pip install selenium pandas keyboard
💡 Edge Profile: Profil Edge tersimpan di D:\Tools\selenium_edge_profile\Stockbit. Ubah path ini di tiap notebook jika beda komputer.
1
🔐 Login Stockbit
login.ipynb
  • Jalankan semua cell di login.ipynb
  • Browser Edge akan terbuka dan navigasi ke Stockbit
  • Login secara manual di browser (Google Login)
  • Setelah login berhasil, tekan tombol Q di keyboard untuk menutup browser
  • Sesi tersimpan — tidak perlu login ulang selanjutnya
⚠️ Jangan tutup browser manual lewat tombol X — gunakan tombol Q agar sesi tersimpan dengan benar.
2
📋 Scraping Daftar Emiten
scrap-list-perusahaan.ipynb
  • Jalankan semua cell di notebook ini
  • Script akan auto-login menggunakan sesi yang tersimpan
  • Loop 10 sektor × sub-sektor secara otomatis
  • Output tersimpan ke List-Perusahaan/Perusahaan.csv
  • Cek output: harus ada ~826 baris
💡 Jika ada sektor yang gagal (error), script akan skip dan lanjut ke sektor berikutnya. Cek log output untuk detail.
3
💹 Scraping Harga Saham
scrap-all-harga.ipynb
  • Jalankan semua cell di notebook ini
  • Script membaca daftar ticker dari Perusahaan.csv
  • Download data OHLCV untuk tiap emiten
  • Hasil disimpan ke Dataset/[KODE].JK.csv
4
📊 Scraping Broker Summary
scrap-broker-summary.ipynb
  • Pastikan koneksi internet stabil (proses panjang 4–8 jam)
  • Jalankan semua cell — bisa ditinggal berjalan
  • Script auto-pause jika internet putus, lanjut ketika pulih
  • Skip ticker yang datanya sudah lengkap (incremental)
  • Data broker di-append ke CSV yang sudah ada
⚠️ Jangan matikan komputer saat script berjalan. Jika terpaksa berhenti, jalankan ulang — script akan melanjutkan dari ticker yang belum selesai.
5
🔄 Update & Migrasi CSV
update_existing_csvs.py
  • Jalankan script via terminal / command prompt
  • Menambahkan kolom Sektor & Sub_Sektor ke semua CSV
  • File yang sudah punya kolom tersebut akan di-skip otomatis
python update_existing_csvs.py
6
🧪 Verifikasi Data
test-read.ipynb
  • Buka test-read.ipynb dan jalankan cell verifikasi
  • Cek jumlah file CSV di Dataset/ (harus 775)
  • Cek kolom yang ada di beberapa sample CSV
  • Validasi tidak ada data kosong di kolom kritis
